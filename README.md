# Prompt & Sword — headless-сим (фазы 0–2)

Боевое ядро роуглайк-автобатлера, где билд — это текст. Полная проработка: [prompt_and_sword_plan.md](prompt_and_sword_plan.md).

## Запуск

```bash
pnpm install
pnpm test          # юнит-тесты (включая критерии Ворот A)
pnpm sim gateA     # статистика: 5 наборов IR × 50 сидов + тест дивергенции
pnpm sim run rush 1  # подробный лог одного боя (набор, seed)
pnpm sim demo-run 1  # мини-забег целиком: карточки, бои, скрипторий
```

Наборы для `run`: `rush`, `focus-leader`, `turtle`, `guard-mage`, `kite`, `rush-variant`.

## Что реализовано

- **IR** ([src/ir.ts](src/ir.ts)) — 12 концептов MVP: условия (hp ниже X, врагов больше, союзник в опасности), селекторы (ближайший, слабейший, лидер), действия (атаковать, защищать, держать позицию, отступать), пространство (рядом с, позади).
- **Линзы характеров** ([src/lens.ts](src/lens.ts)) — детерминированные трансформации IR: трус (прикрывать → стоять позади, штраф рискованным правилам, бегство при hp<30%), фанатик (отступление → атака, игнор ZoC), буквалист (нет правила → глухая оборона).
- **Боевое ядро** ([src/battle.ts](src/battle.ts), [src/grid.ts](src/grid.ts)) — сетка 8×8, инициатива по скорости, фланг/LoS/ZoC, seeded RNG (mulberry32), event-sourced лог.
- **Utility-скоринг** ([src/scoring.ts](src/scoring.ts)) — инстинкты (класс/характер) + веса сработавших правил; топ-3 фактора каждого решения пишутся в лог.
- **Конструктор принципов** ([src/constructor.ts](src/constructor.ts), [src/vocab.ts](src/vocab.ts)) — фразы из чипсов словаря → IR без LLM; закрытый концепт — ошибка компиляции, не догадка.
- **Карточки «как понял»** ([src/cards.ts](src/cards.ts)) — шаблонный обратный перевод IR после линзы; искажения помечены ⚠ и видны до боя.
- **Спарринг** ([src/sparring.ts](src/sparring.ts)) — тот же seed, переписанные принципы; дифф: исход, раунды, потери, раунд расхождения.
- **Мини-забег** ([src/run.ts](src/run.ts)) — 5 боёв, скрипторий между ними (концепты/слоты), пермасмерть, всё детерминировано сидом забега.

Инвариант: тот же seed + те же принципы = тот же бой (тест на побайтовое совпадение лога).

## Ворота A — статус

Прогон `pnpm sim gateA` (50 сидов):

| Критерий | Результат |
|---|---|
| Разные наборы правил → статистически разные исходы | winrate 18–92%, длительность 5.5–6.7 раундов, centroid.x 0.55–1.31 |
| Смена 1 правила меняет ход боя в ≥60% сидов | **98%** (исход переворачивается в 54%) |
| Лог решений читается | `pnpm sim run <set> <seed>` — у каждого решения топ-3 фактора с именами правил |

Критерии закодированы в [test/gate-a.test.ts](test/gate-a.test.ts).

## Ворота B — что осталось

Логика фазы 2 готова (конструктор, карточки, спарринг, забег), но Ворота B требуют
играбельного UI и внешних тестеров. Следующий шаг — минимальный веб-интерфейс поверх
этих модулей.

## Сознательно отложено (по плану)

- Способности героев (рывок/залп/лечение) — не нужны для Ворот A.
- Террейн/препятствия — LoS блокируется только юнитами.
- Веб-UI — следующий шаг фазы 2.
- LLM-компилятор — фаза 3.
