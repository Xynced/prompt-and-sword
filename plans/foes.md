# План: Бой — разнообразие врагов

Статус: в работе · команда: `continue foes plan`

## Проблематика

По исходному плану новый враг = новый набор правил, не новый арт — главный
дешёвый источник контента. Сейчас в пуле 7 типов ([src/foes.ts](../src/foes.ts):
рубака, стрелок, вожак, шаман, берсерк, охотник) и один босс. Углубление: новые
поведенческие архетипы, элитные модификаторы-аффиксы (тот же рубака, но
«мстительный»?), синергии пар (шаман прячется за берсерком — уже есть, нужно
больше таких связок), новые боссы как пазлы на контр-формулировку.

Критерий каждого нового врага: он заставляет игрока **переписать принципы**, а
не просто пережить больше hp. Трудности: разведка (`foeIntel`) должна оставаться
читаемой при росте сложности поведения; автобаланс обязан прогонять новых
врагов по слоям кривой; 4-й враг против партии из трёх почти нерешаем
(экономика действий) — значит разнообразие добывается качеством правил, не
количеством тел.

Смежные планы: враги с АОЕ — `aoe`; враги, эксплуатирующие ландшафт —
`battlefield`; их линзы-характеры — `lenses`.

### Рамка: враг = правила, единица контента = паттерн боя

Единица контента здесь не враг сам по себе, а **паттерн** — состав из 2–4
типов врагов, который ломает прошлую выигрышную формулировку игрока. Критерий
из проблематики применяется к паттерну: у каждого состава обязан быть
ответ-контрформулировка, выразимая словами открываемого словаря, и наив
(«все рубят ближайшего») обязан этому составу проигрывать чаще, чем выигрывать.

Враг собирается **целиком из готовой машинерии плана классов**: именованное
оружие (1–3 на врага, кандидаты по каждому — свитч-хиттер сам меняет лук на
топор), активы (heal/bless врагов гейтятся так же, как у Ивы и Радима — гейты
в скоринге сторону не проверяют), пассивы (sneak, regen), линзы общего пула
(трус, дуэлянт, фанатик — читаемая «личность» бесплатно, интел показывает
правила уже после линзы). Новая машинерия — **один пассив `regen`** (тролль).
Новых слов — **ноль**: правила врагов пишутся прямо в IR, словарь игрока не
задет (words-план не пересекается).

### Паттерны боёв

| Паттерн | Состав | Что ломает | Контр в словаре (новых слов не нужно) |
|---|---|---|---|
| **Масса** | 5× крыса | фокус-фул-атаки впустую: тел больше, чем ходов | «бить часто», «накрыть скопление», «узкое место» |
| **Стая** | 3× волк | строй разваливают фланги и толчки | «держать строй»/«рядом с», «защищать», спина к камню |
| **Застрельщики** | 3× пращник + волк | кайт игрока: враг сам кайтит | «враги накатывают» → давить, «узкое место», догнать трусов |
| **Умная элита** | 2× латник + сержант | размазанный урон: они фокусят и лечат строй кличем | «вожака» первым, фланг/толчок вскрывают строй |
| **Ближники + лекарь** | 2× налётчик + костоправ | размен на телах: хил перекрывает урон | **метка** на лекаря, «самый дальний», «стрелок» |
| **Танк + кастеры** | огр + поджигатель + шаман | «руби ближайшего» упирается в 100 hp пробки | «держать интервал», «вне линии огня», дайв: «стрелок» + фланг, толчок огра с прохода |
| **Засада** | душегуб + 2× волк | тыл без охраны: они идут мимо фронта | «защищать N», «прикрывать отход», телохранитель |
| **Таймер** | тролль + 2× пращник | вялый размазанный урон: реген его съедает | фокус + «бить наверняка», ярость/благословение в окно |
| **Дуэль** | поединщик + латник | керри без прикрытия: дуэлянт его выпилит | «приманка», танк-стена, «глухая оборона» |

Босс этим планом не трогается (новые боссы-пазлы — отдельная работа; вождь
орды со свитой остаётся финалом).

### Раскладка по забегу

`foesForNode` остаётся детерминированной (слой/слот → состав); черновик:
слой 1 — масса рядом со старым составом (знакомое против нового), слой 3 —
стая и застрельщики в fight-узлах, умная элита или таймер на элитке; слой 5 —
танк+кастеры на элитке, ближники+лекарь / засада / дуэль в fight-узлах.
Паттернов больше, чем узлов одного забега (~5 боёв за проход) — разнообразие
между забегами. Решение пользователя: раскладка **статичная** (слой/слот, как
сейчас), без пула от runSeed — проще балансировать и мерить.

### Читаемость разведки

Правил на врага ≤3; оружие/актив/пассив `foeIntel` уже печатает. Решение
пользователя: разведку **не расширяем** — вне элиток и босса паттерн впервые
читается по самому бою, поражение с пермасмертью остаётся ставкой (хардкор —
часть игры). Тем важнее читаемость боя: говорящие имена врагов и оружия,
поведение без скрытых пружин.

### Балансовые ворота и риски

- Тезис «4-й враг нерешаем» — про полновесные тела; масса обходит его
  бюджетом на тело (крыса ≈ треть рубаки). Рычаг — число тел.
- Для каждого паттерна — парный смоук «формулировка-до vs контр» (критерий
  Ворот A в миниатюре): наив проигрывает, контр переворачивает.
- Лекарь и тролль удлиняют бои (допуск — урок Ивы: +0.8 раунда не болото);
  мерить rounds по паттернам. Трус-кобольд рискует погоней на полкарты —
  мерить, рычаг — линза plain.
- `balanceSweep` 500 по слоям после каждой волны; Ворота A не задеты
  (scenarios.ts на своих фикстурах) — прогнать для духа.

### Шаги

1. Пассив `regen` (+тест) — вся новая машинерия плана.
2. **Масса + стая**: крысы, волки, составы слоёв 1–3. → verify: спеки,
   узловые винрейты, длина боёв, парный смоук.
3. **Застрельщики**: пращники (2 оружия, линза труса). → verify: наив-мили
   страдает, «накатить»-контр переворачивает; длина погонь.
4. **Умная элита**: латники + сержант (первый вражеский bless). → verify:
   интел читается, фокус сержанта — контр.
5. **Ближники + лекарь**: налётчики (свитч-хиттер) + костоправ (первый
   вражеский heal). → verify: метка лекаря переворачивает бой.
6. **Танк + кастеры**: огр + поджигатель (+ шаман). → verify: дайв/обход
   бьёт пробку, наив упирается.
7. **Засада + таймер**: душегуб, тролль. → verify: телохранитель-контр;
   тролль без фокуса непробиваем, с фокусом падает.
8. **Дуэль**: поединщик. → verify: приманка/танк уводит дуэлянта от керри.
9. Раскладка `foesForNode` целиком, перебаланс 500, Ворота A, README/индексы.
