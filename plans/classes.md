# План: Бой — классы и активные способности

Статус: в работе · команда: `continue classes plan`

## Проблематика

Способности героев сейчас пассивные: врождённые правила с флейвор-именем
(«Оплот», «Чутьё» в [src/heroes.ts](../src/heroes.ts)). Активных действий из
исходного плана (рывок, залп, лечение) нет — их отложили ещё на Воротах A.
Активка — это решение «когда потратить», и оно идеально ложится на язык
принципов: «лечи того, кто ниже трети», «рывок на стрелка», «залп, когда их
куча». Класс становится диалектом: у кого какие действия есть, тому такие слова
и нужны.

Трудности: новые виды действий в скоринге и кандидатах; кулдауны/заряды — новые
условия словаря («способность готова»); линза обязана искажать и активки («трус
бережёт рывок для побега» — план `lenses`); главный риск — раздуть боёвку, когда
по плану вся глубина должна жить в слое принципов, а не в ворохе механик.

Смежные планы: слова для активок — сверять с `words`; искажения — с `lenses`;
АОЕ-активки — с `aoe`.

### Рамка: класс = оружие + актив + диалект

Класс — по мотивам pf2e, 8 базовых, у каждого **два варианта**, вариант = герой
(имя героя и есть «имя класса» в забеге). Вариант собирается из трёх вещей,
две из которых уже есть в движке:

1. **Оружие** (`WeaponSpec` — обобщение `AoeSpec`): носитель урона, дальности
   и манер. Урон и дальность переезжают **с юнита на оружие** — у юнита
   остаются maxHp/speed/move. Это делает возможным «мастера трёх оружий».
2. **Актив** — способность «когда потратить» со спекой и лимитами
   (`usesPerBattle`/`cooldown` — механизмы ритуала), гейт словом — прецедент
   «накрыть скопление».
3. **Диалект** — слова, осмысленные только с этим классом (прецедент: barrage
   мертво без носителя). Новых слов — минимум, где можно гейтить
   существующими — гейтим ими.

Не каждому варианту нужен актив: у мастера оружия фишка — само оружие.
Это главная защита от раздувания боёвки (риск из проблематики).

### Оружие вместо atk

```ts
interface WeaponSpec {
  name: string;   // «меч и щит», «костяной лук» — идёт в разведку и карточку
  dmg: number;    // заменяет atk юнита
  range: number;  // заменяет range юнита
  /** Родные манеры оружия: родной — премия, чужой — штраф. МЯГКО: слово игрока перебивает. */
  affinity?: Partial<Record<'weakAttack' | 'attack' | 'selflessAttack', 1 | -1>>;
  aoe?: AoeSpec;  // площадные формы — переезжают в оружие (Лия, Жало, шаман…)
}
```

- У героя `weapons: WeaponSpec[]` (1–3); кандидаты атак генерируются **на
  каждое оружие** (кандидат несёт `weaponIdx`) — адаптивность сама выпадает из
  жадного цикла: копьё против строя, молот против щитоносца.
- **Аффинность — не запрет** (решение пользователя): вес `WEAPON_AFFINITY_BONUS`
  ≈ 1.2 против `STRIKE_STYLE_BONUS` 2.5 — приказ «бить отчаянно» перебивает
  нелюбовь щита к отчаянному. Без приказа щитник сам не тянется.
- **Враги — тоже на оружии** (одно на юнита, с именем): «ржавый тесак»,
  «костяной лук» — имя видно в разведке и логе. Поведенчески враги без
  аффинности не меняются — старые фикстуры обязаны выжить (урок АОЕ-плана).
- В симе у юнита остаются производные `atk`/`range` (максимум по оружию) для
  угрозы (`threatAt`), селекторов (`shooter`) и досягаемости; конкретная
  атака считает урон и дальность по своему оружию.

### Новая машинерия (по возрастанию цены)

- метка в бою: действие вешает тег `marked` — селектор готов;
- кара / тень: пассивы на существующих каналах (`lastAttackerId`, линия огня);
- скидка цены действия (Незыблемость): одна ветка в `apCostFor`;
- финт: переиспользует статус `exposed`;
- **длящиеся баффы** (Ярость, Благословение): новый статус по образцу `exposed`,
  снимается концом боя, а не следующим ходом;
- групповое прикрытие (Стена): множественный `coverLevel` одним действием;
- **лечение** (Ива): первый «hp вверх» — главный балансовый риск плана
  (удлиняет бои); мерить длину боёв отдельно.

### Слова

Черновик: «ярость» (DEEP, волна 1), «лечить» (CORE, волна 2). Стена и Метка

по уроку АОЕ: трус бережёт ярость, фанатик лечит только себя?.. — 2–3 штуки
после замеров.
