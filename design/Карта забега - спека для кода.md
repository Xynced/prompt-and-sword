# Карта забега: спека на реализацию (варианты 1a + 1b)

Источник истины по виду: `Карта забега - шаблоны.dc.html`, **1a** (тропа целиком)
и **1b** (развилка крупным планом). Рендер: `design/карта.png`.
Структура настоящая из `src/run.ts` (`LAYER_KINDS`, `generateMap`, `edgeSlots`):
8 слоёв, 15 узлов — урок · бой, бой · скрипторий, событие · бой, элитка, бой ·
привал, скрипторий · элитка, бой · событие, скрипторий · босс.
Токены — `src/ui/style.css`, новых цветов нет.

## 1. Что решает панель

Один вопрос: **куда пойти и чем за это заплатить**. Валюта выбора — интел:
`intelVisible(node)` возвращает true только для урока, элитки и босса, поэтому
именно они показывают состав врагов заранее. Обычный бой всегда покупается
слепо, и это его цена.

## 2. Тропа (1a)

### Шапка
`ТРОПА` · `слой N из 8 · seed` · справа чипсы состояния забега:
`слов 7` (ink), `фокусы 3` (контур), `отряд 4 живы` (red).

### Граф
Слои — колонки, узлы — **крупные клетки** (min-height 66px): глиф вида + подпись
типа. Сквозь колонки идёт горизонтальная полосочка-тропа (ink-22, 1px) — узлы
сидят на ней. Подписей «слой N» над колонками нет.

Состояния клетки (без дополнительных значков внутри — читается фоном и рамкой):

| состояние | вид |
|---|---|
| ты здесь | залитый red, cream-глиф |
| пройдено | залитый ink, cream-глиф, opacity 0.7 |
| доступно сейчас | red-контур + red-06 фон, red-глиф |
| дальше по тропе | пунктирный ink-контур, ink-45 глиф |

Глифы вида: `⚔` бой · `⚑` элитка · `✦` скрипторий · `☾` привал · `?` событие ·
`✎` урок · `✝` босс. Легенда снизу повторяет и состояния, и глифы.

Доступность берётся из `node.next` текущего узла, а не из отдельного списка.

### Карточка узла (право, 250px)
Клик по любой клетке — cream-панель с полоской вида сверху:
- имя вида + состояние (`ты здесь` / `пройден` / `доступен` / `дальше по тропе`);
- описание узла (для боёв — состав по `foesForNode`, словами);
- **кто ждёт** — чипсы врагов с hp, но только при `intelVisible`; иначе строка
  «кто ждёт — неизвестно: интел дают только урок, элитка и босс»;
- **что даст** — награда узла из `run.ts` (обычный бой — 3 обычных, элитка —
  3 редких, урок — «пара обычных или одно редкое», скрипторий — слово либо +1
  слот, привал — лечение);
- **чем грозит** — одна строка Caveat, red: настоящая цена (дедлайн, hp отряда);
- `идти сюда` — только для доступных узлов; иначе строка «туда дороги нет».

## 3. Развилка (1b)

Тот же выбор без графа — для момента, когда решение уже надо принять:
две дороги подряд, каждая полоской слева (доступная — red, вторая — ink-30):

- имя узла + пометка `интел открыт` / `интел закрыт`;
- при открытом интеле — чипсы врагов с hp; при закрытом — строка «кто ждёт —
  узнаешь на месте»;
- `даст:` одной строкой serif, ключевое жирным (три редких / три обычных слова);
- `грозит:` одной строкой Caveat red — конкретика этого забега («Лия входит с
  19/40»);
- подвал: две кнопки по дорогам, доступная — залитая ink.

Блока «куда тропа приведёт всё равно» нет: панель отвечает только за текущий шаг.

## 4. Инварианты

- Палитра: ink, red, два cream-тона; состояние всегда читается фоном/рамкой,
  а не третьим цветом и не значком внутри клетки.
- Интел показывается ровно там, где его даёт код — панель не «помогает».
- Награды и риски пишутся словами и настоящими числами узла.
- Тропа идёт только вперёд: пропущенная ветка честно помечена как недостижимая.
