# Экран боя и расстановка: спека на реализацию (варианты 1a + 1b)

Источник истины по виду: `Экран боя - шаблоны.dc.html`, **1a** (просмотр боя) и
**1b** (расстановка). Рендеры: `design/01-бой.png` (кадр решения),
`02-бой.png` (кадр реакции — актор Огр).
Данные настоящие: партия из `src/heroes.ts` (Яр воин 56, Лия волшебница 40,
Скала паладин 96, Ива жрица 44), враги — `src/foes.ts`, задача —
«Сорвать ритуал» (`RITUAL_DEADLINE = 9`). Токены — `src/ui/style.css`,
новых цветов нет.

Место в коде: боевой экран в `src/ui/main.ts` (`frames`, `frameIdx`,
`battleReveals`), расстановка — фаза перед `battle`.

## 1. Общий принцип

Единственный экран, где игрок **ничего не решает**: он читает последствия своих
слов. Значит вся работа интерфейса — сделать причину видимой: чей ход, по чьему
приказу, что перевесило. Кадр = одно решение, не секунда времени.

## 2. Просмотр боя (1a)

### Шапка
`⚑ задача` · `элитка · слой 5 · seed 4417` · справа чипсы `раунд N` (ink) и
`дедлайн 9` (red, только если у задачи есть дедлайн).

### Поле
Сетка 18 колонок, клетка 20px, gap 2px, фон ink-05.
- зона расстановки — левые 3 колонки, тонкая рамка + вертикальная штриховка;
- камни — залитый ink-50; клетки высоты — рамка + подпись `+1`;
- юниты: свои — залитый ink с cream-литерой, враги — red с cream-литерой;
- **актор кадра** — cream-кольцо 2px + внешний ink-контур (`box-shadow`), и это
  единственная подсветка; актор берётся **явным полем кадра** (`frame.actor`),
  а не выводится из перемещений — иначе кадры реакций остаются без актора;
- юнит никогда не стоит в клетке камня — позиции проверять по проходимости.

### Блок «сейчас · кто и почему» (право, 250px)
Cream-фон, red-полоска сверху. Внутри:
1. цена ромбами (`◆`, `◆◆`, `◇` для реакции) + текст решения с числами броска;
2. строка `по твоему приказу` — какое слово сработало («„бей самого опасного“ —
   огр перед ритуалистом»); для реакций врага — «его реакция, не твой приказ»;
3. реплика характера (Caveat, red, левая полоска) — только при первом
   срабатывании искажения, как в свитке.

### Лента решений
Четыре последних кадра: номер `раунд.кадр` + текст; текущий — полный ink,
прошлые — ink-55. Ниже кнопка `весь свиток` (открывает панель свитка боя).

### Транспорт
`‹` `›` по кадру · `▶ играть / ❙❙ пауза` (залитый ink) · скорости `×1 ×2 ×4`
(активная залита) · подпись «пробел — пауза, стрелки — по кадру».
Полоска кадров: засечка на кадр, пройденные ink-45, текущая red и выше.

### Полоса отряда
Четыре колонки: **имя + класс** (mono 9, red, uppercase — класс читается сразу,
он определяет, чего от героя ждать) · hp числом · полоска (red, если ниже
половины) · подпись состояния или комплекта приказов.

## 3. Расстановка (1b)

Последний момент, когда игрок действует.

- поле с подсвеченной зоной расстановки (red-рамка, red-06 фон); поставленные
  герои — залитые клетки, непоставленный — **пунктирная клетка** с литерой;
- восточная часть видна только если карта куплена разведкой (`2a`); иначе туман;
- список «кто с каким комплектом идёт»: имя + класс, обрывок текста приказов,
  переключатель `A / B / C` (пустой комплект — пунктир, недоступен);
  непоставленный герой комплект не выбирает — сначала клетка;
- подвал: `приказы` (открывает редактор, до первого кадра бесплатно) и
  `⚔ выступить` — **неактивна, пока весь отряд не на поле**.

## 4. Инварианты

- Ромб = очко / слот / фокус; `◇` = реакция или пустое.
- Числа броска прописаны числами; ступень MAP — та, что применилась.
- Палитра: ink, red, два cream-тона. Третьего акцента (золото и пр.) нет —
  выделение актора решается формой и контуром, не новым цветом.
- Голос персонажа — Caveat, механика — serif, служебное — mono.
- Партия на всех панелях одна и та же: расстановка и полоса отряда не могут
  расходиться по составу.
