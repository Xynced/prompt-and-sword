# Редактор приказов: спека на реализацию (утверждённый вариант 2a)

Источник истины по виду: `Редактор приказов - шаблоны.dc.html`, вариант **2a**
(варианты 1a/1b ниже в файле — история; из 1a взята только эхо-колонка, она
переехала в модалку ввода). Рендеры: `design/01-редактор.png` (набор),
`02-редактор.png` (модалка текста), `03-редактор.png` (словарь),
`04-редактор.png` (пустой комплект C).

Место в коде: экран приказов в `src/ui/main.ts` (карточки принципов,
`orders-text`), компиляция — `src/compiler/*`, словарь — `src/vocab.ts`
(`COMMON_WORDS` / `RARE_WORDS`). Токены — `src/ui/style.css`, новых цветов нет.

## 1. Модель взаимодействия

Текст пишется **один раз в модалке**, применяется — и дальше игрок работает с
**набором принципов**, а не с прозой. Оригинальный текст хранится целиком
(включая слова, которых герой не знает) и доступен через «править текст».

```
[ модалка ] текст + эхо → применить → [ панель ] набор чипсов + фокус → выступить
```

## 2. Панель набора

### Шапка
`ПРИКАЗЫ · ЯР` · `воин · слоты ◆◆◆◇` · справа кнопка `словарь · 7 слов` и
счётчик `фокусы: 1 свободен из 3` / `занято 3 из 3` — словами, не дробью.

### Комплекты A / B / C
Три сохранённых комплекта приказов на героя, переключение в один клик:
активный — залитый ink, пустой — пунктирная рамка. Справа подпись комплекта
(«штурм — как ты дрался в прошлом бою»). Переключение бесплатно и вне боя.
У каждого комплекта своё: текст, набор принципов, фокус.

### Цитата оригинала
Блок ink-06 с курсивной цитатой текста (обрезается по ширине) и кнопкой
`править текст` → модалка.

### Строка принципа
Ромб фокуса · чипсы IR в порядке «условие → действие → цель» · справа статус
понимания (`понял дословно` / `понял по-своему` красным).
**Вес не показывается вообще** — закрытая переменная; фокус — единственный
доступный игроку рычаг приоритета.

Чипсы: редкое слово — залитый red, обычное — залитый ink; роль в фразе видна
порядком, не цветом.

### Фокус
Клик по строке ставит/снимает фокус: ромб `◇` → `◆` red, левая полоска red,
фон red-08, подпись `фокус` в строке статуса. Один фокус на героя.
Бюджет фокусов — **общий на отряд** (3 на партию): при нуле свободных подсказка
«сними у другого героя, если этот принцип важнее». Кикер справа —
`фокус — важнее остальных`.

### Свободные слоты
На каждый незанятый слот героя — пунктирная строка `◇ свободный слот — допиши
приказ или оставь ему свободу` со счётом `слот N из M`; клик открывает модалку.
Слоты приходят от `hero.slots`, растут в скриптории.

### Подвал
`сохранить набор` + строка состояния («комплект A сохранён · переключение
бесплатно» / «есть несохранённые правки в комплекте A») · `⚔ выступить`.

## 3. Модалка ввода текста

Оверлей внутри панели (скрим ink-55), содержимое **всегда от текущего
комплекта**:

- шапка: `ТВОЙ ТЕКСТ · КОМПЛЕКТ A` + `он знает 7 слов`;
- слева поле ввода (serif 15.5): незнакомые слова подсвечены red-18 с пунктирным
  подчёркиванием прямо в тексте; подпись «перепиши или оставь — в набор это
  просто не войдёт»;
- справа эхо-колонка на ink-06 — три состояния и ни одного четвёртого:
  `понял дословно` (печатаем правило), `понял по-своему` (только факт, Caveat —
  содержание раскроет свиток боя), `не понял вообще` (перечисление непонятых
  кусков + чипс-догадка «может, „держать дистанцию“?»);
- состояния, которых нет, **не рисуются** (у комплекта B нет «не понял вообще»);
- подвал: «текст сохранится целиком — даже те слова, что он пока не понимает» ·
  `отмена` · `применить`.

Пустой комплект: пунктирное поле с плейсхолдером, эхо «пока нечего понимать»,
`применить` неактивна — уйти в состояние «набор без принципов» невозможно.

## 4. Словарь (оверлей)

Открывается кнопкой из шапки; в шапке панели виден только счёт слов.

- шапка `СЛОВАРЬ · ЯР` + `7 из 38 слов`, `закрыть`;
- ряд фильтров по роли слова со счётом: `все 7` · `условия 2` · `цели 1` ·
  `действия 4`; подпись «клик по слову — вставить в текст»;
- группа **Редкие** (`RARE_WORDS`): чипс залитый red + короткая расшифровка
  serif («лучший селектор боя», «условие: враги со всех сторон»);
- группа **Обычные** (`COMMON_WORDS`): контурный чипс + расшифровка;
- группа **Ещё не открыто**: только `?` и счёт (`? ещё 28`) — **названия
  закрытых слов не показываются**, иначе это спойлер трофея.

Рост словаря к концу забега держат фильтры; поиск добавить, если групп станет
больше четырёх.

## 5. Инварианты

- Ромб = очко / слот / фокус; `◇` — свободное или не выбранное.
- Три состояния понимания — исчерпывающий набор, четвёртого не вводить.
- Вес, скоринг и имена линз игроку не показываются нигде, кроме debug.
- Максимум два фоновых тона; голос персонажа — Caveat, механика — serif,
  служебное — mono.
- Панель не советует, что писать: подсказка возможна только как «может,
  „слово“?» рядом с непонятым куском.

## 6. Открытые вопросы

- Фокус: жёстко один на героя или два ценой всего бюджета отряда.
- Нужен ли поиск в словаре при 38+ словах или хватит фильтров.
