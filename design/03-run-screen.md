# Задача 3. Основной экран похода

Контекст, дизайн-система, правила и формат сдачи — в [INDEX.md](INDEX.md).
Шкала и плотность — из задачи 1; тумблеры уже уехали по задаче 2.

## Что есть сейчас

Разворот 960×640. **Слева**: карта из 15 узлов (SVG, 5 слоёв, ветвление),
панель текущего узла, подвал с тумблерами. **Справа**: состав отряда — на
каждого героя имя, класс, hp, **полный текст приказов** и рукописные реплики
«как понял», плюс шапка с «экспорт билда / переписать».

Панель текущего узла показывает разное в зависимости от вида узла (`nodePanelHtml`):

- **бой** (виды: урок / бой / элита / босс) — название места, задача боя
  («⚑ Обезглавить — вожак должен пасть»), список врагов со статами, кнопка
  «пометить» цель фокус-огня, разведка принципов врага (только урок/элита/босс),
  мини-поле расстановки с ландшафтом и врагами, кнопки «⚔ выступить» /
  «переписать приказы» / «пропустить урок»;
- **трофей после победы** — 2–3 варианта слов на выбор;
- **выбор пути** — «Куда дальше? Выбери следующий узел на карте»;
- **привал** — лечение;
- **событие** — книжник / тайник / наёмник;
- **скрипторий** — отдельный экран-лавка со словами.

## Проблемы

1. **Ростер тонет в тексте приказов.** Правая страница — стена прозы: у
   каждого героя 1–6 фраз приказов плюс 1–6 реплик «как понял». То, что нужно
   в походе постоянно (жив / hp / сколько слотов памяти занято), теряется.
2. **Нельзя посмотреть, куда идёшь.** Клик по узлу карты **сразу** переносит
   отряд (`advance()` в `src/run.ts`) — узел раскрывается только после того,
   как выбор сделан. Развилка «бой или скрипторий» решается вслепую.
3. **Ресурсов не видно, потому что их нет.** Появляются разведка и фокус —
   счётчикам нужно место, заметное, но не главное.
4. **Артефактов ещё нет**, но место под них надо зарезервировать сейчас, иначе
   потом они выдавят что-то живое.

## Задача

Пересобрать экран похода. Состав того, что должно быть видно **одновременно**:

1. **Состав отряда** — как сейчас по духу (имя, класс, hp), но **без текста
   приказов и без реплик «как понял»**. Добавить: занятые слоты памяти
   (`занято/всего`, сейчас 4 на старте, максимум 6), состояние (жив / ранен /
   пал). Клик по герою — лист героя (задача 4).
2. **Карта похода** — сохранить как есть по существу, это удачная часть.
   Ромбы-узлы, глифы видов (`α` урок, `×` бой, `✕` элита, `?` событие,
   `~` привал, `§` скрипторий, `Ω` босс), пройденное/текущее/доступное,
   рукописное «ты здесь».
3. **Превью узла до фиксации выбора.** Главное новшество. Наведение или первый
   клик по доступному узлу показывает, что там: вид узла, название места,
   задача боя, кто противник (числом), будет ли разведка. Переход — вторым,
   явным действием («идти сюда»). Спроектировать оба состояния: «смотрю» и
   «решил».
   Честность: на обычном бою принципы врага скрыты — превью не должно их
   выдавать (см. правило 2 в INDEX).
4. **Описание текущего боя** — задача боя, противник, арена, расстановка,
   метка фокус-огня, кнопки действия. Это остаётся, но должно перестать быть
   сплошным столбцом мелкого моно.
5. **Счётчики ресурсов — разведка и фокус.** Два числа с иконкой-глифом,
   постоянно на виду. Показать состояния: пусто / есть / потрачено только что
   (краткая обратная связь). Что они покупают — см. открытый вопрос 2 в INDEX;
   для макета годится рекомендация оттуда.
6. **Полка артефактов** — зарезервированное место, по умолчанию пустое.
   Пустые гнёзда должны читаться как обещание («сюда что-то ляжет»), а не как
   поломка. Нужны оба состояния: пустая полка и полка с 2–3 артефактами
   (название + короткий эффект по наведению).

## Что сдать

Один HTML-файл со **всеми состояниями экрана**, подписанными:

1. узел-бой, разведки нет;
2. узел-элита с разведкой (видны принципы врагов);
3. превью соседнего узла (наведение) и то же после решения идти;
4. выбор трофея после победы;
5. привал и событие (компактно, можно один из двух);
6. полка артефактов пустая и заполненная;
7. пометка «нечестный забег» из задачи 2 — как она сидит на этом экране.

## Критерии приёмки

- Состав отряда читается за секунду: кто жив, у кого сколько hp, у кого
  свободны слоты памяти.
- Текста приказов на этом экране нет вообще.
- Из карты понятно, куда можно пойти, **и** что там, — до того как выбор сделан.
- Ресурсы и артефакты видны, но не спорят с картой за главное место.
- Экран стал реже: меньше одновременных элементов, чем сейчас, при большем
  количестве информации.

## Данных нет

- **Ресурсы «разведка» и «фокус»** — в `RunState` нет ни одного счётчика
  (есть только словарь, герои, метка, расстановка, трофей, режим нерва).
  Нужны: величина, потолок, источники пополнения, на что тратятся.
- **Артефакты** — механики нет полностью: ни типа, ни выпадения, ни эффектов.
- **Превью узла** — данные для него есть (вид узла, сценарий, состав врагов
  считаются из узла заранее), но интерфейса «посмотреть, не переходя» нет:
  `advance()` переносит сразу. Разделение «посмотреть / пойти» — пункт на
  реализацию.
- **Слоты памяти** в модели есть (`START_SLOTS = 4`, `MAX_SLOTS = 6`), но в
  ростере не показываются.
