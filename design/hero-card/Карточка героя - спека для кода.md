# Карточка героя: спека на реализацию (утверждённый вариант 3a)

Источник истины по виду: `Действия - шаблоны v2.dc.html`, вариант **3a**. Данные в
макете — настоящий кит Яра (`src/heroes.ts`, id `yar`). Токены брать из
`src/ui/style.css` (`--serif`, `--mono`, `--red`, `--ink-45`), новых цветов не вводить.
Место в коде: оверлей карточки юнита в `src/ui/main.ts` (`.unit-card`, ~стр. 2280+),
строки приёмов вместо текстового `describeWeapon`/`describeMove` из `src/cards.ts`.

## 1. Шапка (одна полоска, всегда видна)

`ИМЯ` (uppercase, serif 15) · `класс · подпись архетипа` (mono 9, ink-45) ·
справа `hp 56 · КБ 17 · приказы 2/4` (mono 10, ink-45).
Ничего больше: очки хода одинаковы у всех и в шапку не идут.

## 2. Вкладки

Три равных таба под шапкой, активный — залитый `ink` фон, неактивные — тонкая
рамка без нижней границы: **Описание · Приёмы · Инвентарь**. Дефолт — «Приёмы».

### Вкладка «Описание»

1. **Характеристики** — сетка 2 колонки, точечные лидеры: жизни, инициатива, шаг.
2. **Защиты и спасброски** — чипсы `КБ 17` (залитый) + `стойкость 10`, `реакция 7`,
   `воля 6` (контурные), под ними одна строка-вывод о слабейшем спасброске.
3. **Урон: как его берут** — строки `сопр N` (залитый ink) / `слаб N` (залитый red) /
   `имм` (контур) + расшифровка типа словами. Источник: `defenses.resist / weak /
   immune` (`plans/damage-types.md`). До открытия разведкой — чипс `?`.
4. **Характер** — линзы чипсами, неоткрытые как `? ещё не открыто` (пунктир), плюс
   строка о том, как линза искажает приказ.
5. **Способность** — врождённое правило, рукописным (Caveat), red.

Навыков как сущности в коде ещё нет; когда появятся — ряд чипсов между 2 и 3.

### Вкладка «Приёмы»

Группировка по оружию (анти-доминация из `plans/weapon-moves.md`).

- Заголовок оружия: `НАЗВАНИЕ` (red, uppercase) · `тип · урон · дальность` · справа `+atkBonus`.
- Строка приёма: ромбы цены (`◆` = 1 очко, `◆◆` = 2) · имя (serif 16) ·
  райдер пунктиром, если есть (`пробивает укрытия`, `открывает`) · справа чипсы
  `+9 / +4 / −1` (три ступени MAP прописаны числами) и урон (red).
- Отдельные секции: **Ход и оборона** (осторожный шаг, прикрыться) и **Реакция**
  (`◇`, «одна в раунд — на всё», чипс `+9 · без повтора`).
- Клик по любой строке (приём, заголовок оружия, общее действие, реакция) —
  попап-карточка справа; повторный клик или «закрыть» — свернуть. Попап живёт
  только на этой вкладке.

**Попап**: имя · строка меты (оружие · темп · цена · тип · дальность) · чипсы
(атака / урон / райдер) · абзац пояснения (2–3 строки) · опционально прямоугольник
под схему с подписью · опционально строка «какое слово это заказывает» (Caveat, red).
Тексты попапов уже написаны в `DETAILS` в логике макета — переносить как есть.

### Вкладка «Инвентарь» — заглушка

Плашка `в разработке` в углу, список полупрозрачный: предмет = имя + строка
«что он даёт» (`молот → пролом, сплеча`; `свиток воинских тренировок → слова
«бить часто», «бить наверняка»`), плюс пустой слот пунктиром. Смысл, который
должен читаться: предметы — источник приёмов и слов; убрал молот — исчезли его
приёмы во вкладке приёмов.

## 3. Инварианты

- Ромб = очко хода, пустой ромб = реакция; одна азбука во всех панелях
  (карточка героя, разведка врага, свиток боя).
- Три числа броска всегда прописаны словами/числами, не иконками.
- Максимум два фоновых тона, шрифты только из style.css.
- Всё, что длиннее строки, уходит в попап — список остаётся сводкой на один взгляд.
